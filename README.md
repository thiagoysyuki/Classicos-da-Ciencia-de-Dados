# Clássicos da Ciência de Dados

## Os casos mais famosos e interessantes da ciência de dados

Este repositório reúne uma coleção de casos clássicos e notáveis na área de ciência de dados. Cada caso inclui uma descrição detalhada, o conjunto de dados utilizado, a metodologia aplicada e os resultados obtidos. O objetivo é fornecer uma referência valiosa para estudantes, profissionais e entusiastas da ciência de dados.

Este repositório é mantido por [Thiago Yuki](https://resolvedortech.com.br) e está disponível sob a licença MIT. Sinta-se à vontade para contribuir com novos casos ou melhorias nos existentes através de pull requests.

## Detalhes Técnicos

- Linguagens: Python, R
- Bibliotecas: Pandas, NumPy, Scikit-learn, TensorFlow, Keras, Matplotlib, Seaborn
- Ferramentas: Jupyter Notebooks, RStudio, Git, Quarto
- Python Version: 3.12
- R Version: 4.3.1
